# Security Policy

## Supported Versions

Currently, the following versions are being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability within this project, please responsibly disclose it.

You can report a vulnerability by:
- Using GitHub's built-in private advisory feature.
- Or contacting us directly via email at rutova2@gmail.com.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress. If you have not received a reply to your email within 48 hours, or have not heard from us for the past 5 days, please contact us again.
